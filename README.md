# Syllabus Hub

A modern, interactive, and visually stunning web application designed to help users explore structured learning programs. Master your field step-by-step with detailed modules, topics, and interactive roadmap visualizations.

## 🚀 Features

- **Interactive Roadmaps:** Visualizes complex learning paths using an interactive node-based canvas.
- **Modern Glassmorphic UI:** A beautifully designed interface with premium, dynamic aesthetics, sleek dark modes, and subtle micro-animations.
- **Fully Responsive:** Carefully optimized to look stunning on mobile phones, tablets, laptops, and ultra-wide desktop monitors.
- **Dynamic Search:** Instantly search through available syllabuses, course modules, and specific topics.
- **Interactive Modals & Sidebars:** Full-screen original syllabus image viewer and smooth sliding drawers for course navigation.

## 🛠️ Technologies Used

This project is built with a modern, high-performance tech stack:

- **[React](https://react.dev/)** - Core library for building the user interface.
- **[Vite](https://vitejs.dev/)** - Next-generation, blazing fast frontend tooling.
- **[Tailwind CSS](https://tailwindcss.com/)** - Utility-first CSS framework for rapid, highly-customizable UI development.
- **[React Router v6](https://reactrouter.com/)** - For seamless client-side routing.
- **[React Flow (@xyflow/react)](https://reactflow.dev/)** - Powering the interactive, node-based roadmap canvas.
- **[Lucide React](https://lucide.dev/)** - Beautiful, consistent icon set.

## 📦 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/gagandeepsinghs/Syllabus-Hub.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Syllabus-Hub
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the Vite development server:
```bash
npm run dev
```
Then, open `http://localhost:5173` in your browser to view the application.
